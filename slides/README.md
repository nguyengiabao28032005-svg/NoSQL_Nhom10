## Danh mục tài liệu trong thư mục:
1. **`Slide_Thuyet_Trinh_Do_An.md`**:
   - Dàn ý chi tiết gồm 14 slide chuẩn học thuật được thiết kế bám sát yêu cầu môn học NoSQL và Đề tài 05.
   - Trình bày mạch lạc: Đặt vấn đề $\rightarrow$ Kiến trúc $\rightarrow$ Thiết kế CSDL Redis $\rightarrow$ Kỹ thuật then chốt (ZSET, SSE, Anti-Cheat, Tie-Breaking) $\rightarrow$ Benchmark $\rightarrow$ Kết luận.

## Hướng dẫn sử dụng:
- Bạn có thể mở file `Slide_Thuyet_Trinh_Do_An.md` và sao chép nội dung vào Microsoft PowerPoint, Google Slides hoặc Canva để tạo file trình chiếu (`.pptx`).
- Khi xuất ra slide trình chiếu, bạn có thể lưu file `.pptx` hoặc `.pdf` trực tiếp vào thư mục này để nộp đính kèm bài làm.
