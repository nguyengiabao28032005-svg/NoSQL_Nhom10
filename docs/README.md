# THƯ MỤC HỒ SƠ ĐẶC TẢ HỆ THỐNG

Thư mục này phục vụ cho **Yêu cầu 1: Hồ sơ đặc tả** trong hồ sơ nộp bài cuối khoá.

---

## Tài liệu trong thư mục:
- **`Ho_So_Dac_Ta_He_Thong.md`**: Hồ sơ đặc tả hệ thống toàn diện, chi tiết từ bối cảnh, yêu cầu chức năng/phi chức năng, kiến trúc 3 tầng, đặc tả CSDL Redis (String, Hash, List, Set, Sorted Set), đặc tả API, giải thuật Tie-Breaking, cơ chế chống gian lận và hướng dẫn cài đặt.

## Xuất ra file Word (.docx) hoặc PDF:
- Bạn có thể mở file `Ho_So_Dac_Ta_He_Thong.md` trên VS Code (hoặc trình đọc Markdown bất kỳ) và sử dụng tính năng **Markdown to PDF / Word** để xuất ra file tài liệu nộp bài chính thức.
- Bạn cũng có thể lưu trực tiếp file `.docx` hoặc `.pdf` đã xuất vào thư mục này để nộp đính kèm.
